iPhone 虚拟定位软件

FakeGPS 是一款免费、开源、免越狱的 iPhone 虚拟定位工具。连接 iPhone，选择地点，立即生效。

免费使用开源透明支持 Windows / macOS支持 GPX 轨迹

FakeGPS 能做什么

你可以在地图上点击位置、搜索地点或输入经纬度，将 iPhone 的临时 GPS 位置设置到指定地点。国内地图支持高德坐标，海外地图支持全球图层，并自动处理 GCJ-02 与 WGS-84 坐标转换。

地图点选

打开地图，点击目标位置，确认后即可设置 iPhone 虚拟位置。

地点搜索

搜索城市、地标和地址，也可以直接填写纬度与经度。

GPX 轨迹

导入 GPX 文件，按照文件中的时间和速度播放移动路线。

如何使用 iPhone 虚拟定位

  1. 在电脑上安装 FakeGPS，并使用数据线连接 iPhone
  2. 在 iPhone 上信任此电脑，按系统提示完成设备准备
  3. 在地图上选择位置，点击“设置位置”即可生效

FakeGPS 支持 iOS 16 及以上版本。iOS 17 及以上系统可能需要按提示授权隧道服务。

安全、隐私与开源

FakeGPS 不需要在 iPhone 上安装 App，不要求越狱，也不会将定位数据上传到第三方服务器。项目源码公开在 GitHub，软件仅用于学习、测试和研究，请遵守当地法律法规。

常见问题

FakeGPS 免费吗？

FakeGPS 以 MIT License 开源，可免费下载和使用。

Windows 上如何安装？

下载 Windows 安装包后，可以在安装向导中选择目标路径。

macOS 上如何安装？

打开 DMG，将 FakeGPS 拖入 Applications 文件夹即可。

可以播放 GPX 文件吗？

可以。程序按照 GPX 文件提供的时间和速度信息播放轨迹。
