fakeGPS
iPhone 虚拟定位

基于 pymobiledevice3，无需越狱，无需 Xcode。
支持 GUI 地图界面和 CLI 命令行两种操作方式。

下载 查看源码
核心功能

为什么选择 fakeGPS

一个工具，覆盖虚拟定位的所有场景。简洁、高效、开源。

🗺️

GUI 地图交互

基于高德地图 + OSM 的可视化界面，直接在地图上点选目标位置。

$ fakegps gui
→ 点击地图选择坐标
→ 自动应用定位
⌨️

CLI 命令行

完整的 REPL 交互模式，适合自动化脚本和高级用户。

$ fakegps cli
❯ set 39.9087 116.3975
✓ Location set
🚶

GPX 路线模拟

导入 GPX 文件，按真实速度模拟步行或驾车路线移动。

$ fakegps play route.gpx
→ 按距离÷速度定时
→ 模拟真实移动轨迹
🔄

坐标系自动转换

内置 GCJ-02 与 WGS-84 坐标系互转，中国境外自动切换 OSM。

GCJ-02 ⇄ WGS-84
中国境内 → 高德瓦片
国际区域 → OSM 瓦片
📍

全球地标预设

内置天安门、埃菲尔铁塔等全球热门地标，一键定位。

tiananmen ... 39.91°N
eiffel ...... 48.86°N
times_sq .... 40.76°N
📦

多种安装方式

npm、pip、Homebrew 安装，也提供打包好的可执行文件。

npm i -g fakegps
brew install fakegps
+ .app / .exe 下载
快速开始

即刻启动

选择你偏好的安装方式，几秒钟即可完成部署。

Downloads
# 全局安装（自动识别 macOS / Windows）
npm install -g fakegps
 
# 首次运行自动下载对应平台二进制
fakegps
# 选择你的平台，点击下载
 
🍎 macOS (.app)
🪟 Windows (.exe)
 
# 备用：macOS 镜像 | Windows 镜像
 
# Windows 需安装 Apple Devices 并以管理员运行
# 安装核心包
pip install fakegps
 
# 安装 GUI 依赖（可选）
pip install fakegps[gui]
 
# 启动
fakegps gui
# 克隆源码
git clone https://github.com/sixzjd/fakeGPS-for-iPhone.git
cd fakeGPS-for-iPhone
 
# 安装依赖 & 启动
pip install -r requirements.txt
python run_gui.py
